# 多彩词汇 · 单词表

多彩词汇 v11 是一个在浏览器中使用的词汇学习网站。它把个人单词表和 AI 词汇解析放在同一页面：左侧整理、筛选和复习词条，点击单词后在右侧查看解析；也可以切换为仅词表或仅查词。

## 快速开始

已发布的网站无需安装软件。打开站点后：

1. 点击左侧「查看示例」，页面会出现三条示例词；也可以点击「导入单词表」选择自己的 XLSX、CSV 或 TXT 文件。
2. 点击一个词条，右侧查询框会自动填入该词。首次生成没有缓存的解析时，展开右侧「连接 DeepSeek」，输入**自己的** DeepSeek API Key 并保存，然后查询。已有缓存的解析无需重新生成。
3. 如需跨设备保存数据，点击右侧账号按钮，使用 Firebase 邮箱账号登录。顶部出现「词表已同步」表示处理后的词表已经同步完成。未登录也能使用词表，但数据只保存在当前浏览器。

在左侧看到词条、点击后右侧显示对应查询，即表示页面已正常加载。需要新解析时还必须能访问 DeepSeek API；账号同步则需要能访问 Firebase。

## 主要功能

| 功能 | 用法与结果 |
|---|---|
| 导入词表 | 支持 `.xlsx`、`.csv`、`.txt`，也可拖入文件。多 Sheet XLSX 会合并有效词条；导入时过滤常见标题、空行和重复项。单个文件上限为 30 MB、100000 个词条。 |
| 词表管理 | 可新建、切换、重命名或删除词表，新增或删除词条。导入成功后以网站内的数据为准，后续修改不依赖原文件。 |
| 生词表 | 首次使用自动创建空的专属生词表；普通词表的词条旁点「＋」加入，点「✓」移出。生词表可重命名但不可删除，支持查看加入时间与来源，也可勾选或全选筛选结果后批量删除词条。可导出带加入时间和来源的 CSV 或 XLSX。 |
| 查找与复习 | 左侧可搜索、按收藏或标记筛选，并按导入顺序、字母正倒序或乱序排列。点「乱序」可重新洗牌，保持乱序模式时每次刷新页面都会重新打乱显示顺序；词条的存档顺序不变。可隐藏释义；长按词条或点击操作按钮进行收藏、标记和删除。 |
| 双栏联动 | 点击左侧单词在右侧发起查询，并自动将查询区滚动到视野中央。收藏独立保存在右侧「我的词库」，不会自动加入左侧词表。左侧导入区可随页面上滑，搜索与词表切换栏到顶后固定，词条继续在同一滚动区域滑动。分隔线可拖至边缘切成单栏。 |
| 词汇解析 | 右侧支持单词、短语和中文表达查询，显示流式生成的解析；可查看最近查询、收藏和复习进度。 |
| 导出与备份 | 当前词表可下载 CSV 或 XLSX，包含单词、释义或备注、分组、标记与收藏状态；全部处理后词表可备份为 JSON，并从 JSON 存档恢复。下载文件由浏览器保存到其默认下载位置。 |

自动过滤采用规则判断，复杂表格可能仍需导入后检查。必要时可使用「清理疑似标题」，并在词表中删除错误词条，必要时重新添加。

## 数据与账号

词表首先保存在浏览器本地，优先使用 IndexedDB；不可用时回退到 localStorage。登录后，处理后的词表名称、词条、备注、分组、顺序、标记和删除记录会同步到该账号的 Firestore。右侧的查询历史、已完成解析、收藏和复习进度也按账号同步。不同账号的数据相互隔离；原始 XLSX、CSV、TXT 文件不会上传。

DeepSeek API Key 仅保存在当前标签页会话，不进入云端，也不应写入仓库。排序、分栏宽度、主题等界面偏好保存在当前设备。更换网站地址时，浏览器不会自动转移旧地址的本地数据；可在旧页面导出「备份全部词表」JSON，再在新地址「导入旧存档」，或登录已完成云同步的同一账号。

## 在本地运行

本仓库是静态网页，没有 `package.json`、安装步骤或构建命令。需要现代浏览器和网络连接，以加载 Firebase SDK、登录账号及生成解析。为完整测试登录与模块脚本，建议通过 HTTP 打开，而不是直接双击 `index.html`。

如果电脑已安装 Python 3，在**本仓库根目录**运行：

```bash
python3 -m http.server 8000
```

然后打开 `http://127.0.0.1:8000/`。正常情况下会显示左侧「我的单词表」和右侧「多彩词汇」；按上面的快速开始步骤导入示例即可验证交互。按 `Ctrl+C` 停止本地服务器。此命令只提供静态文件，不代理 DeepSeek 请求。

## 文件结构与实现

```text
index.html                       双栏网站入口
wordlist.js                      XLSX、CSV、TXT 解析、过滤与导出
workspace_sync_core.js           词表分片、合并及删除记录
workspace_cloud.js               Firebase 登录状态与词表云同步
dictionary_workspace_right.html  右侧 v11 查词页面
workspace_bridge.js              左右两侧的查询与收藏消息
workspace_right_enhancements.js  右侧快捷目录交互
vendor/fflate.min.js             XLSX 压缩文件读写所需的本地库
dictionary_workspace.html        双栏入口的同版本副本
dictionary_v11.html              v11 单独查词页面
dictionary_v10.5.html            保留的原版查词页面
```

`index.html` 在父页面管理词表，右侧通过同源 `iframe` 加载查词页；两侧使用 `postMessage` 传递查询和收藏操作。导入文件在浏览器中解析、过滤和去重，再写入本地词表。`workspace_cloud.js` 把处理后的词表拆分为 Firestore 文档并与登录账号合并；右侧查词页独立同步解析、历史和收藏。项目使用原生 HTML、CSS、JavaScript、Firebase 和 DeepSeek，无前端打包器。

本发布仓库不包含自动化测试或本地 API 代理。若要自行部署并使用**自己的**云同步服务，需要将 `workspace_cloud.js` 和 `dictionary_workspace_right.html` 中的 Firebase 配置改为自己的项目，并配置只允许用户访问本人数据的 Firestore 规则。当前发布文件指向项目现有的 Firebase 服务；仅复制网页文件不会自动创建独立数据库。

## 常见问题

- **点击词条后没有生成解析**：先确认右侧查询框已填入该词；若提示缺少 API Key，展开「连接 DeepSeek」并保存自己的密钥。
- **提示 `Failed to fetch`**：静态网站由浏览器直连 DeepSeek，网络或跨域限制可能阻止请求。需要在可访问的网络环境下重试，或另行配置可用的 API 代理。
- **新设备看不到词表**：确认使用同一个 Firebase 账号，并等待顶部显示「词表已同步」。未登录时的数据只在原浏览器本地。
- **导入结果少于表格行数**：空行、标题和重复词条会被过滤；可查看各个 Sheet 的内容及导入后的词条数。
